#Первичный анализ данных (Курсовой проект)

Репозиторий содержит практическую часть курсового проекта по исследованию и предобработке разнородных типов данных (таблицы, временные ряды, изображения, текст).

## Структура проекта

Проект разделен на логические модули в соответствии с главами работы:
* **Раздел 1. Табличные данные** — Первичный разведочный анализ и очистка структурированных наборов данных.
* **Раздел 2. Временные ряды** — Анализ многомерных временных рядов (потребление энергии, метеоданные), аддитивная декомпозиция (выделение тренда, сезонности, шума) и расчет отношения сигнал/шум (SNR).
* **Раздел 3. Компьютерное зрение** — Предобработка датасетов для разметки в формате YOLOv8.
* **Раздел 4. Обработка текста (NLP)** — Конвейер очистки текстовых данных: токенизация, фильтрация регулярными выражениями, лемматизация с помощью `pymorphy3` и векторизация методом `TF-IDF`.

## Стек технологий

* **Язык разработки:** Python 3.12+
* **Анализ данных:** `pandas`, `numpy`, `scipy`
* **Машинное обучение и статистика:** `scikit-learn`, `statsmodels`
* **Визуализация:** `matplotlib`, `seaborn`, `wordcloud`
* **Обработка текста:** `pymorphy3`, `nltk`
